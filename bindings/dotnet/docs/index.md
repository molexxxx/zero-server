# zero-server for .NET

The API reference of the `ZeroServer` packages, generated by DocFX from the sources in
`bindings/dotnet/src`.

- [`ZeroServer.Core`](api/ZeroServer.Core.yml): the version of the compiled core.
- [`ZeroServer.Native.Interop`](api/ZeroServer.Native.Interop.yml): the P/Invoke declarations
  of the C ABI, generated from `zero.h`, and the helpers over its owned strings, buffers and
  statuses.
- [`ZeroServer`](api/ZeroServer.yml): the exception a failed operation throws.

There is no server API for .NET yet; the declarations reach every export of the C ABI.
